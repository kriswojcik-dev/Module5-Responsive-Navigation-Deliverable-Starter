2. Breakpoint evidence

Method and widths tested: I checked the homepage in Chrome at viewport widths of 511 and 512 CSS pixels. The navigation links stacked at 511 px. At 512 px, all five fit on one row without horizontal scrolling.

First content failure: The five links needed about 470 CSS pixels to fit on one row, including link padding, gaps, and header padding. Below that estimated width, there is too little room for the row at its full size. The exact width where a label first wraps or the row overflows is still to be verified.

Chosen breakpoint in relative units: I chose 32rem, which was 512 CSS pixels in the test. This gives the links about 42 px of extra room beyond the estimated minimum.

Long-label and zoom retest: Pending. I’ll check the navigation with longer labels, at a 320 CSS-pixel viewport, and at 200% browser zoom, then record what happens and any changes I make.
