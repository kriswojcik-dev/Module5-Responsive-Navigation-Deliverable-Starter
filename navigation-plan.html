5. JavaScript code defense

Explain initialization, state synchronization, activation, and Escape/focus behavior in your own words. Refer to the exact variable, attribute, dataset value, function, and event used.

The script uses `button` to find the Menu button and `list` to find the navigation links. The `if (button && list)` check makes sure both elements exist before the script attaches any event handlers. Once the handlers are ready, `setMenuOpen(false)` sets the initial state to closed, and `button.hidden = false` reveals the working button. If JavaScript is unavailable, the button stays hidden and the links remain visible. The `setMenuOpen(isOpen)` function writes `"true"` or `"false"` to `aria-expanded`. Assistive technology can read that state, and the narrow-screen CSS uses the same attribute to decide whether to show the links. At wide widths, CSS hides the button and keeps the links visible in a row. On a `click` event, the script reads `aria-expanded` and passes the opposite state to `setMenuOpen`. Because Menu is a native button, Enter and Space activate the same click handler. The `keydown` handler listens on the navigation so it can receive Escape from the button or a link. It checks that the key is Escape, that the layout is narrow, and that the menu is open. If all three are true, it closes the menu with `setMenuOpen(false)` and returns keyboard focus to Menu with `button.focus()`.
